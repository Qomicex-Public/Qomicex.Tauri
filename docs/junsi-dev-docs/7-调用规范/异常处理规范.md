# 异常处理规范

## 后端异常处理

### 原则

- Controller/Endpoint 中不添加 try/catch
- 预期错误抛出 `ApiException`
- 未处理异常由 `ErrorHandlingMiddleware` 统一捕获

### ApiException 用法

```csharp
ApiException.BadRequest("INVALID_PARAM", "参数无效")
ApiException.NotFound("INSTANCE_NOT_FOUND", "实例未找到")
```

### 异常 → HTTP 映射

| 异常类型 | HTTP 状态码 | 说明 |
|:---|:---|:---|
| ApiException | 自定义 | 按 ApiException.Code 映射 |
| ArgumentNullException | 400 | 参数为空 |
| FileNotFoundException | 404 | 文件未找到 |
| HttpRequestException | 502 | 上游请求失败 |
| TaskCanceledException | 499 | 请求超时/取消 |
| JsonException | 400 | JSON 解析错误 |
| 其他 | 500 | 服务器内部错误 |

### 错误响应格式

```json
{
  "code": "ERROR_CODE",
  "message": "...",
  "detail": "...",
  "traceId": "...",
  "timestamp": "...",
  "status": 500
}
```

## 前端异常处理

### ApiError 类

```typescript
import { ApiError } from '../api/client.ts'

try {
  // ...
} catch (e) {
  if (e instanceof ApiError) {
    showToast(e.displayMessage)
  }
}
```

### ApiError 属性

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| `.code` | string | 错误码 |
| `.status` | number | HTTP 状态码 |
| `.detail` | string | 详细错误信息 |
| `.traceId` | string | 追踪 ID |
| `.displayMessage` | string | 用户可读的错误信息 |
