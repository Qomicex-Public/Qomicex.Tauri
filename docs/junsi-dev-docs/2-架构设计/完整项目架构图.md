# Qomicex Launcher 完整项目架构图

## 项目概述
Qomicex Launcher 是一个基于 Tauri v2 的 Minecraft 启动器，采用 React + Rust 技术栈，支持跨平台（Windows、Linux、macOS）。

## 技术栈
- **桌面外壳**: Tauri v2 (Rust) - `src-tauri/`
- **前端**: React 19 + Vite 7 + TypeScript + Tailwind - `src/`
- **后端 API**: Rust (axum + tokio) - `src-backend/qomicex-backend/`
- **UI 组件库**: `@qomicex/plugin-ui` - `packages/plugin-ui/`

## 数据流架构

### 1. 启动流程
```
用户点击启动 → App.tsx → RunningContext → LaunchProgressDialog
    ↓
api/instance.ts → POST /api/instance/{id}/launch
    ↓
endpoints/launch.rs → services/launch_tracker.rs
    ↓
游戏进程启动 → SSE 推送进度 → 前端更新 UI
```

### 2. 下载流程
```
用户选择资源 → DownloadCenter → api/instance.ts
    ↓
POST /api/instance/{id}/install → services/install_service.rs
    ↓
下载任务队列 → qomicex-downloader-rust
    ↓
SSE 推送进度 → useDownloadSSE → 前端更新进度条
```

### 3. 联机流程
```
用户创建房间 → Connect → api/connector.ts
    ↓
POST /api/connector/host → endpoints/connector.rs
    ↓
qomicex-connector-rust → EasyTier 虚拟网络
    ↓
其他用户加入 → POST /api/connector/join → 房间同步
```

### 4. 插件流程
```
插件安装 → POST /api/plugins/upload → plugins/installer.ts
    ↓
插件激活 → plugin-loader.tsx → renderInline/createSandbox
    ↓
插件 API 调用 → window.__PLUGIN_API__ → plugin-api.ts
    ↓
后端代理 → POST /api/plugins/proxy → endpoints/plugin.rs
```

## 关键方法说明

### 前端关键方法
- **activatePlugin()**: 激活插件，注入 CSS/JS
- **launchInstance()**: 启动游戏实例
- **useDownloadSSE()**: SSE 流式下载进度
- **usePageAnimation()**: GSAP 页面切换动画

### 后端关键方法
- **AppState::build()**: 构建应用状态
- **build_router()**: 组装 API 路由
- **install_instance()**: 安装实例（Mod/整合包）
- **launch_instance()**: 启动游戏进程
- **handle_connector_room()**: 联机房间管理

## 架构特点

1. **前后端分离**: React 前端 + Rust 后端，通过 HTTP/IPC 通信
2. **插件系统**: 支持 inline/iframe/WASM 三种插件模式
3. **跨平台**: Tauri v2 支持 Windows/Linux/macOS
4. **实时通信**: SSE 推送下载/启动进度
5. **模块化**: 清晰的分层架构（页面/组件/API/服务）
6. **类型安全**: TypeScript + Rust 强类型
7. **国际化**: 支持中文/英文切换
8. **主题系统**: 支持深色/浅色模式、自定义主题

## 数据流架构

### 1. 启动流程
```
用户点击启动 → App.tsx → RunningContext → LaunchProgressDialog
    ↓
api/instance.ts → POST /api/instance/{id}/launch
    ↓
endpoints/launch.rs → services/launch_tracker.rs
    ↓
游戏进程启动 → SSE 推送进度 → 前端更新 UI
```

### 2. 下载流程
```
用户选择资源 → DownloadCenter → api/instance.ts
    ↓
POST /api/instance/{id}/install → services/install_service.rs
    ↓
下载任务队列 → qomicex-downloader-rust
    ↓
SSE 推送进度 → useDownloadSSE → 前端更新进度条
```

### 3. 联机流程
```
用户创建房间 → Connect → api/connector.ts
    ↓
POST /api/connector/host → endpoints/connector.rs
    ↓
qomicex-connector-rust → EasyTier 虚拟网络
    ↓
其他用户加入 → POST /api/connector/join → 房间同步
```

### 4. 插件流程
```
插件安装 → POST /api/plugins/upload → plugins/installer.ts
    ↓
插件激活 → plugin-loader.tsx → renderInline/createSandbox
    ↓
插件 API 调用 → window.__PLUGIN_API__ → plugin-api.ts
    ↓
后端代理 → POST /api/plugins/proxy → endpoints/plugin.rs
```

## 关键方法说明

### 前端关键方法
- **activatePlugin()**: 激活插件，注入 CSS/JS
- **launchInstance()**: 启动游戏实例
- **useDownloadSSE()**: SSE 流式下载进度
- **usePageAnimation()**: GSAP 页面切换动画

### 后端关键方法
- **AppState::build()**: 构建应用状态
- **build_router()**: 组装 API 路由
- **install_instance()**: 安装实例（Mod/整合包）
- **launch_instance()**: 启动游戏进程
- **handle_connector_room()**: 联机房间管理

## 架构特点

1. **前后端分离**: React 前端 + Rust 后端，通过 HTTP/IPC 通信
2. **插件系统**: 支持 inline/iframe/WASM 三种插件模式
3. **跨平台**: Tauri v2 支持 Windows/Linux/macOS
4. **实时通信**: SSE 推送下载/启动进度
5. **模块化**: 清晰的分层架构（页面/组件/API/服务）
6. **类型安全**: TypeScript + Rust 强类型
7. **国际化**: 支持中文/英文切换
8. **主题系统**: 支持深色/浅色模式、自定义主题
