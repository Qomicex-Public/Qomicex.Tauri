## 前端模块

| 模块 | 目录 | 职责 |
|:---|:---|:---|
| API 客户端 | `src/api/` | 19 个模块封装所有后端 HTTP 调用，含 `ApiError` 类 |
| 页面 | `src/pages/` | 12 个路由页面组件 |
| UI 组件 | `src/components/ui/` | 16 个 Radix 基元组件(Button, Dialog, Select 等) |
| 领域组件 | `src/components/` | 40 个业务组件 (ModCard, Sidebar, LaunchProgressDialog 等) |
| 状态管理 | `src/stores/` | downloadStore (localStorage)、javaStore |
| 上下文 | `src/contexts/` | RunningContext (运行实例、启动进度、崩溃) |
| Hooks | `src/hooks/` | useCloseGuard, useDownloadSSE, usePageAnimation, useRequireDefaultAccount, useScrollFade |
| 工具库 | `src/lib/` | cn(), simple-cache, skin-avatar, fps-limiter |
| 类型定义 | `src/types/` | 所有共享 TypeScript 类型 (649 行) |
| 常量 | `src/constants/` | credits.ts |

## 后端模块 (Service 层)

| 服务 | 类型 | 职责 |
|:---|:---|:---|
| DefaultGameCore | 单例 | Minecraft 核心引擎 (Core.AOT) |
| InstanceService | 单例 | 实例 CRUD + 持久化 |
| LaunchTracker | 单例 | 游戏进程管理 + 启动进度 |
| DownloadSessionManager | 单例 | 并发下载调度 (max 64) |
| InstallTracker | 单例 | 实例安装进度跟踪 |
| ContentService | 单例 | Mods/Resourcepacks/Saves 交互 |
| AccountService | 单例 | 账户持久化 |
| SkinService | 单例 | 皮肤获取 + 本地覆盖 |
| ModpackService | 单例 | Modpack 解析安装 |
| McmodService | 单例 | MCMOD.cn 中文名称 |
| ConnectorService | 单例 | 在线多人连接编排 |
| JavaRuntimeStore | 单例 | Java 运行时缓存 |
| JavaDownloadService | 单例 | Java 运行时下载 |
| TraceBufferStore | 单例 | 内存追踪缓冲区 |
