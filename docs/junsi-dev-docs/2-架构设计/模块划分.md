### 基础设施

- `app.rs` — 路由组装（`Router::nest("/api", ...)`），CORS 用 `CorsLayer::permissive()`
- `state.rs` — `AppState`（`Arc` 共享）+ `DEFAULT_PORT = 5000`
- `settings.rs` — 应用设置加载
- `error.rs` — 统一错误类型（thiserror）
- `middleware/not_found.rs` — 404 fallback（先于 CORS layer 注册，保证跨域 404 也带 CORS 头）
- `util/sysinfo.rs` — 系统信息（sysinfo crate）
