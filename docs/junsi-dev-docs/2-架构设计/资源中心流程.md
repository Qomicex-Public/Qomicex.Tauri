# 资源中心流程（ResourceCenter）

## 概述

资源中心提供跨平台资源搜索、浏览、安装功能，支持 **Modrinth**、**CurseForge** 和 **FTB** 三大数据源。用户可从资源中心浏览 Mod、资源包、光影包、数据包，查看详情并一键安装到指定实例。

## 页面与路由

| 页面 | 路由 | 组件 |
|:---|:---|:---|
| 资源列表 | `/resource-center` | `ResourceCenter` (`src/pages/ResourceCenter.tsx`) |
| 资源详情 | `/resource-center/:resourceId` | `ResourceDetailPage` (`src/pages/ResourceDetail.tsx`) |

## 搜索流程

```
用户输入关键词 + 选择分类 + 数据源
  │
  ▼
GET /api/resources/search?source={s}&keyword={k}&type={t}&gameVersion={v}&loader={l}&page={p}
  │
  ▼
返回分页结果 [{ id, name, description, iconUrl, author, downloads, ... }]
  │
  ▼
用户选择资源 → 跳转 `/resource-center/:resourceId`
```

**前端组件**：
- 搜索栏：关键字输入 + 下拉筛选（分类/数据源/游戏版本/加载器）
- 结果列表：`ModCard`、`ResourcePackCard`、`ShaderCard`、`DataPackCard`
- 分页控件

## 资源详情流程

```
GET /api/resources/{id}?source={s}                     → 元数据
GET /api/resources/{id}/versions?source={s}&...        → 版本列表
GET /api/resources/{id}/dependencies?source={s}&...    → 依赖树
GET /api/resources/{id}/translate?source={s}           → 中文翻译
  │
  ▼
展示：图标、名称、作者、描述（Markdown 渲染）、下载量、分类标签
版本列表：按游戏版本 + 加载器筛选
依赖树：可递归展开
```

## 安装流程

```
用户选择版本 → 点击"安装到实例"
  │
  ▼
弹出 ResourceInstallDialog
  ├── 选择目标实例（下拉选择器）
  └── 如果资源是 Modpack → 弹出 ModpackInstallDialog
  │
  ▼
POST /api/resource-download/start 或
POST /api/resource-download/download-to
  │
  ▼
SSE `/api/progress/stream` 接收进度 → DownloadCenter 显示任务
```

## 异步 CurseForge 版本拉取

CF API 列表分页限制导致大量版本需异步拉取：

```
POST /api/resources/{id}/versions/start-fetch    → 返回 taskId
GET  /api/resources/versions/fetch-progress/{id}  → 轮询进度
GET  /api/resources/versions/fetch-result/{id}    → 获取结果
```

## 翻译系统

- `GET /api/resources/{id}/translate`：预翻译的中文名称和描述
- `POST /api/resources/translate-text`：实时翻译任意文本（MyMemory / Google 引擎）
- MCMOD 补充：`GET /api/mcmod/lookup` 从本地数据库查找中文对应

## 资源补全

资源补全用于检查实例中已安装资源的更新：

```
POST /api/resources/complete    → 开始检查
GET  /api/resources/complete/progress → 补全进度
```

### 2026-08-02 更新
## 存档（Saves/Worlds）分类

资源中心新增「存档」分类（`category=save`），用于浏览并安装 CurseForge 世界存档。

### 数据源限制

- **仅 CurseForge 支持**（`classId=17`，World 分类）。Modrinth 无存档项目类型，FTB 无存档，故前端选中存档分类时自动切换到 CurseForge；切到其他数据源时自动回到 mod 分类。
- 前端分类 Tab：`source !== 'curseforge'` 时禁用「存档」Tab。

### 后端映射

- `ResourceCenterEndpoints.MapCfClassId`：`save → 17`。
- `ResourceCenterEndpoints.MapCfUrlSlug`：`save → worlds`（搜索卡片与详情页「原站」链接）。
- 详情接口 `GET /api/resources/{id}` 新增可选 `category` 参数，用于生成正确的 CurseForge URL slug。

### 安装流程

- 存档下载与其他分类一致：`POST /api/resource-download/start`，`category=save` 映射到 `saves` 目录（版本隔离时为 `versions/{inst.Name}/saves`）。
- **自动解压**：下载完成后，若文件为 `.zip` 且分类为 saves，后端 `ResourceDownloadEndpoints` 会将其解压到 saves 目录并删除压缩包（`ZipFile.ExtractToDirectory`），使世界立即可玩。
- 本地存档管理（列表/重命名/备份/删除）仍由实例详情页的存档 Tab 提供（`GET/POST/DELETE /api/instance/{id}/files/saves*`）。

### 关键文件变更

| 层 | 文件 | 变更 |
|:---|:---|:---|
| 前端 | `src/pages/ResourceCenter.tsx` | 新增存档分类 Tab + 来源限制逻辑 |
| 前端 | `src/api/resource.ts` | `getResourceDetail` 透传 `category` |
| 前端 | `src/pages/ResourceDetail.tsx` | 详情请求带上 `category` |
| 后端 | `Endpoints/ResourceCenterEndpoints.cs` | CF classId/slug 映射 + 详情 category 参数 |
| 后端 | `Endpoints/ResourceDownloadEndpoints.cs` | 存档下载后自动解压 |

## 全部（All）聚合数据源

资源中心新增「全部」数据源 Tab（`source=all`），一次浏览三个数据源的结果。

### 聚合规则（后端 `resource_center.rs::search`）

- `source=all` 时按分类决定聚合哪些源：
  - `save` → 仅 CurseForge（其他源无存档）
  - `modpack` → Modrinth + CurseForge + FTB
  - 其余分类 → Modrinth + CurseForge
- 各源用相同 `page`/`pageSize` 查询，结果合并后按下载量降序排序，截取 `pageSize` 条返回。
- `total` 为各源 total 之和（近似值）；FTB 无分页，翻页时 FTB 结果会重复出现。
- 聚合排序统一按下载量，故「全部」源仅提供「下载量」排序选项。

### 前端（`src/pages/ResourceCenter.tsx`）

- `SOURCES` 新增 `{ key: 'all', label: '全部' }` Tab；切到「全部」时 `sort` 置为 `downloads`。
- 分类 Tab 禁用逻辑：`source=all` 时「存档」不再被禁用（由 CurseForge 覆盖）。
- 单条结果仍带各自 `source` 字段（Modrinth/CurseForge/FTB 徽章、详情跳转、安装均按单条来源处理，无需改动）。
