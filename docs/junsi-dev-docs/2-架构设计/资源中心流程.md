# 资源中心流程（ResourceCenter）

## 概述

资源中心提供跨平台资源搜索、浏览、安装功能，支持 **Modrinth**、**CurseForge** 和 **FTB** 三大数据源。用户可从资源中心浏览 Mod、资源包、光影包、数据包，查看详情并一键安装到指定实例。

## 页面与路由

| 页面 | 路由 | 组件 |
|:---|:---|:---|
| 资源列表 | `/resource-center` | `ResourceCenter` (`src/pages/ResourceCenter.tsx`) |
| 资源详情 | `/resource-center/:resourceId` | `ResourceDetailPage` (`src/pages/ResourceDetail.tsx`) |

## 搜索流程

```
用户输入关键词 + 选择分类 + 数据源
  │
  ▼
GET /api/resources/search?source={s}&keyword={k}&type={t}&gameVersion={v}&loader={l}&page={p}
  │
  ▼
返回分页结果 [{ id, name, description, iconUrl, author, downloads, ... }]
  │
  ▼
用户选择资源 → 跳转 `/resource-center/:resourceId`
```

**前端组件**：
- 搜索栏：关键字输入 + 下拉筛选（分类/数据源/游戏版本/加载器）
- 结果列表：`ModCard`、`ResourcePackCard`、`ShaderCard`、`DataPackCard`
- 分页控件

## 资源详情流程

```
GET /api/resources/{id}?source={s}                     → 元数据
GET /api/resources/{id}/versions?source={s}&...        → 版本列表
GET /api/resources/{id}/dependencies?source={s}&...    → 依赖树
GET /api/resources/{id}/translate?source={s}           → 中文翻译
  │
  ▼
展示：图标、名称、作者、描述（Markdown 渲染）、下载量、分类标签
版本列表：按游戏版本 + 加载器筛选
依赖树：可递归展开
```

## 安装流程

```
用户选择版本 → 点击"安装到实例"
  │
  ▼
弹出 ResourceInstallDialog
  ├── 选择目标实例（下拉选择器）
  └── 如果资源是 Modpack → 弹出 ModpackInstallDialog
  │
  ▼
POST /api/resource-download/start 或
POST /api/resource-download/download-to
  │
  ▼
SSE `/api/progress/stream` 接收进度 → DownloadCenter 显示任务
```

## 异步 CurseForge 版本拉取

CF API 列表分页限制导致大量版本需异步拉取：

```
POST /api/resources/{id}/versions/start-fetch    → 返回 taskId
GET  /api/resources/versions/fetch-progress/{id}  → 轮询进度
GET  /api/resources/versions/fetch-result/{id}    → 获取结果
```

## 翻译系统

- `GET /api/resources/{id}/translate`：预翻译的中文名称和描述
- `POST /api/resources/translate-text`：实时翻译任意文本（MyMemory / Google 引擎）
- MCMOD 补充：`GET /api/mcmod/lookup` 从本地数据库查找中文对应

## 资源补全

资源补全用于检查实例中已安装资源的更新：

```
POST /api/resources/complete    → 开始检查
GET  /api/resources/complete/progress → 补全进度
```
