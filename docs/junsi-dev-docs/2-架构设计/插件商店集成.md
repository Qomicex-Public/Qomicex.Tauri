## 架构：后端代理（方案 B）

**上游服务**：`https://plugins.qomicex.top/api/v1`（规格见 https://docs.qomicex.top/store/）。
**关键约束**：商店写操作 CORS 仅放行 `*.qomicex.top`，Tauri WebView 源不在白名单 → 认证/安装等写操作必须经 Rust 后端代理。

### 后端（`src-backend/qomicex-backend/src/`）

- `services/plugin_store.rs`：商店客户端
  - 公开读（列表/详情/评价/更新检查）以 `serde_json::Value` 原样透传，上游字段演进零维护
  - 认证 token 仅存后端 `BaseDir/plugin-store-auth.json`，永不下发前端；401 自动 refresh 一次重放，失败清会话
  - 安装管线：`download-info` → 主/镜像 URL 下载（50MB 上限）→ SHA-256 校验 → 复用 `services::plugin::install_from_package`（依赖预检+zip-slip 防护）
  - `check-updates` 由后端注入 `launcherVersion = env!("CARGO_PKG_VERSION")`
  - 上游错误 `{error:{code,message}}` 映射为 `STORE_<CODE>` 大写码 ApiError
- `endpoints/plugin_store.rs`：`/api/store/*` 12 条路由（plugins/plugins/{slug}/reviews/check-updates/download-info/install/auth/login|register|logout|refresh|me/mine），接线于 `app.rs`
- `GET /api/store/auth/me` 未登录返回 `{user:null}` 而非 401（前端免判）

### 前端（`src/`）

- `api/pluginStore.ts`：商店 API 客户端
- `components/PluginStoreTab.tsx`：单卡结构（CardHeader 标题 + CardContent 内 Tabs + 子内容）
- `components/PluginStoreBrowse.tsx`：浏览插件——卡片网格/搜索/分类(tool|launcher|theme|integration)/排序(最新|下载量)/分页；安装流程 = 详情拉权限 → 权限确认 Dialog（风险分级着色）→ `POST /api/store/install` → rescan；详情 Dialog 含版本历史 + 只读评价
- `components/PluginStoreManage.tsx`：原 Settings 插件管理整体迁移 + 新增「检查更新」——收集已装清单（manifest.id 与 slug 双形式去重，兼容 `top.qomicex.x` 反域 id）→ `POST /api/store/check-updates` → 卡片右上角版本徽标
- `components/PluginStoreAccount.tsx`：密码登录/注册/退出 + 我的插件列表（GitHub OAuth、API Key 管理留待后续迭代）
- slug ↔ 本地插件匹配规则：`id === slug || id.endsWith('.' + slug)`（`matchesLocalId`，Browse 与 Manage 各有一份同语义实现）
- Settings.tsx 插件 tab 原 25 行内联区块与全部相关 state/handler 已迁出，替换为 `<PluginStoreTab />`

### 布局设计语言（踩坑记录）

- 设置页每个分类 tab 的内容必须是**单 Card**：`CardHeader(CardTitle) + CardContent(内容)`，内容躺进 CardContent padding，禁止内容组件直接裸排在 Tabs 行下（会贴顶）
- 商店插件卡片：grid 加 `items-start` 防同行拉伸；description 为空时不渲染占位（`min-h-*` 空占位会造成卡片中部空洞）

### i18n

新增 `settings.plugins.store.*` 约 66 key，7 个 locale（zh-CN/zh-TW/zh-HK/en-US/en-GB/ja-JP/ru-RU）全部补齐（zh-CN 为 schema 基准，satisfies 编译期校验结构一致）。i18n 资源在 `qomicex-tauri-i18n` submodule 内修改。
