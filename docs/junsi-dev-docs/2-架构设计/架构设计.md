# 插件系统架构设计

> 日期：2026-07-30
> 状态：草案

## 概述

Qomicex Launcher 插件系统采用**声明式 + WASM 混合架构**，支持从简单主题到复杂 Agent 的全范围扩展。后端 = NativeAOT C#，前端 = React 19 + Vite，桌面壳 = Tauri v2（Rust）。

## 设计目标

- **低门槛**：普通用户通过 JSON 声明即可制作主题、添加下载源
- **高能力**：高级开发者通过 WASM 实现 Agent、协议解析器等复杂逻辑
- **安全隔离**：WASM 沙箱 + iframe 沙箱 + 权限模型三层防御
- **热加载**：声明式插件即装即用，WASM 插件重启网关即可

## 分层架构

| 层级 | 技术 | 适用场景 | 安全模型 |
|------|------|---------|---------|
| L0 静态 | `theme.json` + CSS | 主题、颜色方案、背景图 | 纯声明，无执行能力 |
| L1 声明式 | `manifest.json` 配置 | 新增下载源、镜像、API 端点 | 纯声明，无执行能力 |
| L2 脚本 | JS（iframe 沙箱） | UI 扩展、菜单注入、面板 | postMessage 网关权限检查 |
| L3 WASM | WASM（Wasmtime） | Agent、协议解析器、核心扩展 | Host API 权限门控 |

## 插件包结构

```
my-plugin/
├── manifest.json        # 元数据 + 权限 + 入口 + 扩展点声明
├── theme.json           # [L0] 主题变量
├── theme.css            # [L0] 附加样式
├── plugin.js            # [L2] 前端脚本
├── plugin.wasm          # [L3] 后端 WASM 模块
└── assets/              # 资源文件
```

## Manifest 规范

```json
{
  "id": "com.example.plugin",
  "name": "插件名",
  "version": "1.0.0",
  "minLauncherVersion": "0.2.0",
  "layers": ["l2", "l3"],
  "permissions": ["network:fetch", "instance:read"],
  "entry": {
    "backend": "plugin.wasm",
    "frontend": "plugin.js",
    "theme": "theme.json"
  },
  "contributes": {
    "downloadSources": ["source-id"],
    "commands": ["plugin.command"],
    "settingsPages": ["page-id"],
    "menuItems": [
      { "path": "sidebar", "label": "菜单", "icon": "icon" }
    ]
  }
}
```

## 后端 WASM 引擎

通过 **Tauri Rust 层**运行 wasmtime crate（Rust 原生支持，最稳定）：

```
后端(C#) ──HTTP──→ 插件网关(localhost:动态端口) ──→ Tauri Rust(wasmtime) ──→ WASM 插件
```

**Host API（启动器 → 插件）：**

```
register_endpoint(method, path, handler)
http_fetch(url, headers) → bytes
instance_list() → [...]
db_get(key) / db_set(key, value)
log(level, message)
```

**插件导出（WASM → 启动器）：**

```
on_load() → void
on_unload() → void
get_manifest() → bytes
```

## 前端 JS 沙箱

L2 插件运行在 `<iframe sandbox="allow-scripts">` 内，通过 `postMessage` 与主应用通信。渲染内容挂载在 `ShadowRoot` 下实现样式隔离。

**插件 API（`window.__PLUGIN__`）：**

```ts
{
  render(slot: string, html: string): void
  theme(vars: Record<string, string>): void
  addMenuItem(item: MenuItem): void
  getSettings(): Promise<Record<string, any>>
  setSettings(key: string, value: any): Promise<void>
  callBackend(endpoint: string, data?: any): Promise<any>
  onActivate(fn: () => void): void
  onDeactivate(fn: () => void): void
}
```

**插槽（扩展点）：**

| 插槽 | 位置 | 用途 |
|------|------|------|
| `sidebar:bottom` | 侧边栏底部 | 导航项 |
| `settings:pages` | 设置页列表 | 插件设置页 |
| `instance:actions` | 实例详情操作栏 | 自定义操作 |
| `header:right` | 顶栏右侧 | 图标/状态 |
| `dashboard:widgets` | 仪表盘 | 小组件 |

## 权限模型（26 项）

### 实例
- `instance:read` — 读取实例列表
- `instance:write` — 创建/修改/删除实例

### 账号
- `account:read` — 读取账号列表（含 UUID）

### 许可证
- `license:read` — 读取许可证 ID、状态（只读）

### 配置
- `config:read` — 读取启动器配置
- `config:write` — 修改启动器配置

### 网络
- `network:fetch` — 发 HTTP 请求
- `network:websocket` — WebSocket 连接
- `network:proxy` — 修改代理设置

### UI
- `ui:inject_sidebar` — 注入侧边栏项
- `ui:inject_settings` — 注入设置页
- `ui:picture_in_picture` — 画中画窗口
- `ui:sub_window` — 独立子窗口
- `ui:context_menu` — 注入右键菜单
- `ui:toast` — 应用内 Toast

### 系统
- `system:info` — 读取系统和启动器信息
- `system:notification` — 系统通知
- `clipboard:read` — 读取剪贴板
- `clipboard:write` — 写入剪贴板

### WASM
- `wasm:execute` — 执行 WASM 模块

### 插件管理
- `plugin:install` — 安装/卸载/更新插件（高危）

### 资源文件
- `resource:read` — 读取 .minecraft assets/libraries
- `resource:write` — 写入 .minecraft assets/libraries

### Java
- `java:manage` — 管理 Java 运行时

### 游戏进程
- `game:process` — 启停游戏进程

### 系统命令
- `shell:execute` — 执行外部命令（高危）

### 文件系统
- `filesystem:read` — 读启动器目录外文件
- `filesystem:write` — 写启动器目录外文件

### 端点发现
- `endpoint:discover` — 获取后端 API 端点列表

### 内置
- `core:settings_rw` — 读写插件自己的设置（默认拥有）

## 危险级别

- **正常**：只读类权限
- **⚠️ 注意**：config:write、network:proxy 等
- **🚫 高危（安装时红色提示）**：plugin:install、shell:execute、filesystem:write

## 生命周期

```
已安装 → [启用] → 活跃 → [停用] → 已禁用
                        ↓
                    卸载 → 已删除
```

- L0/L1：完全热加载/热卸载
- L2/L3：启用/停用需重启插件网关（秒级）
