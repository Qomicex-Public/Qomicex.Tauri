# 整合包快捷安装对话框（资源中心）

## 触发入口

资源中心 → 整合包分类 → 条目「安装」按钮（`ResourceCenter.tsx` `handleInstall` 整合包分支）。
不再跳转详情页，改为弹出 `ModpackQuickInstallDialog`；「查看详情」按钮保持跳转详情页不变。

## 组件：`src/components/ModpackQuickInstallDialog.tsx`

props：`{ open, onClose, modpackName, projectId, source, iconUrl? }`。

### 打开时
- `loadSettings()` 获取 `gameDir` + `versionIsolation`（整合包为新建实例，用全局设置默认目录）
- `getResourceVersions(projectId, source)` 加载版本列表，按 `datePublished` 降序，默认选中最新版

### 交互
- 版本下拉（Select，复用 `dialogs.resourceInstall.*` 文案）
- 实例名 Input（默认整合包名）
- 「开始安装」→ 复用详情页 ModpackInstallDialog 启动管线：
  `addTask` 占位 → `resolveModpack` → `startModpackInstall` → `removeTask` 占位
  → `onClose()` + `navigate('/downloads')`
- 失败：留在对话框显示错误（`dialogs.modpackInstall.installFailed`），可重试

### 复用 i18n
- `dialogs.modpackInstall.*`：title/modpackLabel/instanceName/startInstall/resolving/gameVersion/installFailed
- `dialogs.resourceInstall.*`：selectVersion/loadingVersions/noVersions/selectVersionPlaceholder/versionsLoadFailed
- 无新增 i18n key
