# I18N 国际化设计

## 概述

Qomicex Launcher 使用轻量自研 i18n 方案（零第三方依赖），支持简体中文 / English 双语即时切换，语言设置持久化到后端 `AppSettings.language` 与 `localStorage`。全部前端页面与组件的硬编码中文文案均已迁移为 `t()` 调用；后端错误消息经前端错误码映射实现多语言展示。

## 架构

```
src/i18n/
  index.tsx            I18nProvider (Context) + useI18n() → { lang, t, setLanguage }
  types.ts             Lang / TranslationSchema / DeepKeys 类型
  errors.ts            后端错误码 → 翻译 key 映射 + translateApiError()
  zh-CN/              中文资源（基准 schema）
    index.ts           总表（合并 16 个模块）
    common.ts          通用按钮/提示
    layout.ts          外壳（侧边栏/标题栏）
    errors.ts          错误消息
    running.ts         启动流程 + 运行页
    settings.ts        设置页（6 个 Tab 分组）
    dashboard.ts / instances.ts / instanceDetail.ts / downloads.ts /
    accounts.ts / accountDetail.ts / resource.ts / resourceDetail.ts /
    connect.ts / plugins.ts / dialogs.ts / tools.ts
  en/                  英文资源（结构必须与 zh-CN 完全一致）
```

### 核心机制

- **Provider 挂载**：`App.tsx` 最外层 `<I18nProvider>`（包住 `RunningProvider`/`MessageBoxProvider`），全局可用。
- **t() 函数**：`t(key, params?)` 取翻译；`{name}` 占位符用 params 替换。key 类型为 `DeepKeys<TranslationSchema>`（递归模板字面量），字面量 key 编译期校验；动态 key（如 `t(\`dialogs.stage.${s}\`)`）通过 `(string & {})` 放宽。
- **类型安全**：`TranslationSchema = DeepStringify<typeof zhCN>`（叶子放宽为 string，仅校验 key 结构）；`en/index.ts` 用 `satisfies TranslationSchema` 编译期强制 zh/en key 结构一致；缺 key 时 `t()` 在 DEV 模式 console.warn 并回退 key 本身。
- **语言持久化与同步**：`localStorage('qomicex-language')` 即时生效；`I18nProvider` 订阅 `onSettingsChange`（后端 `put /settings` 广播），启动加载与多窗口时与 `settings.language` 双向同步。
- **即时切换**：设置页「外观 → 界面语言」下拉 `onChange` 同时 `update('language', v)`（持久化）+ `setLanguage(v)`（即时重渲染，无刷新）。Playwright 实测：切换 English 后侧边栏与设置页全部文案即时变为英文。

### 迁移规范

- 翻译模块命名空间 = 页面/功能域；key 用 camelCase 语义化命名，可按需嵌套对象。
- 组件内 `const { t } = useI18n()`；模块顶层（常量数组/纯函数）不能调 t —— 常量删 label 在渲染处动态 key，纯函数（如 `formatDate(iso, t, lang)`）改为接收 t/lang 参数由调用处传入。
- `useCallback` 依赖数组需补 `t`（若闭包使用）；高频回调可用 `tRef` 模式保持依赖稳定。
- 数据字典（`categoryTranslations.ts` 分类中文、`cape-names.ts` 披风名、`PERMISSION_CATALOG` 权限 label、`KEY_DISPLAY_MAP` 键位名、credits.ts 内容数据）保持中文不迁移。
- 注释、API 字段名、URL、专有名词（Modrinth/CurseForge/Java 等）、`e.message` 错误变量内容不迁移。

### 后端错误消息（前端错误码映射）

- 后端 22 个端点零改动：错误响应已含稳定 `code` 字段。
- `src/api/client.ts` 提供 `setApiErrorTranslator(fn)` 钩子；`ApiError.displayMessage` getter 优先走翻译器。
- `src/i18n/errors.ts` 维护 `CODE_TO_KEY` 映射（`NOT_FOUND`/`FORBIDDEN`/`BAD_REQUEST`/`INTERNAL_ERROR`/`UPSTREAM_ERROR`/`REQUEST_TIMEOUT`/`UNKNOWN_ERROR`/`LICENSE_*` 系列/`TOKEN_EXPIRED`/`MC_API_ERROR`/`FS_AUTHORIZATION_REQUIRED`/`PLUGIN_MISSING_DEPENDENCY`），`I18nProvider` 语言变化时刷新注入；未映射 code 回退后端中文 message。

## 已知遗留

- 插件系统内部文案（`plugin-loader.tsx` 前置依赖错误、`plugin-api.ts` 文件授权 confirm、`installer.ts` 进度消息）为模块顶层函数，需专门设计 t 传递（涉及插件桥接架构），留待后续批次。
- 数据字典（分类/披风/权限/键位名）保持中文，en 用户将看到中文数据名，后续可按需做第二层映射。

## 语言集（2026-08-16 更新）

支持 7 种语言，统一 BCP 47 全码：

| 代码 | 语言 | 说明 |
|---|---|---|
| `zh-CN` | 简体中文 | 基准 schema |
| `zh-TW` | 繁體中文（台灣） | 台湾繁体（檔案/資料/網路/軟體/預設/帳號） |
| `zh-HK` | 繁體中文（香港） | 香港繁体（網絡/軟件/用戶/帳戶/上載/數據） |
| `en-US` | English (US) | 美式英语 |
| `en-GB` | English (UK) | 英式英语 |
| `ja-JP` | 日本語 | 日语 |
| `ru-RU` | Русский | 俄语 |

## 资源结构（2026-08-16 更新）

语言资源在 submodule `qomicex-tauri-i18n/`：

```
qomicex-tauri-i18n/src/
  index.ts                 RESOURCES + GAME_SETTINGS_DESCRIPTIONS 导出（7 语言）
  types.ts                 Lang 联合类型（7 全码） / TranslationSchema / DeepKeys
  {lang}/                  每语言 18 个 TS 模块 + index.ts + game-settings-descriptions.json
```

- 启动器 `src/i18n/`：`index.tsx`（Provider）、`lang.ts`（LANGS/SUPPORTED/detectSystemLang/resolveLang）、`errors.ts`、`types.ts`（re-export）。
- `detectSystemLang()` 映射：zh-hk→zh-HK；zh-tw|zh-mo|hant→zh-TW；en-gb|en-uk→en-GB；en→en-US；ja→ja-JP；ru→ru-RU；其他→en-US。
- 游戏设置描述：后端 `options.rs` 以 `include_str!` 内嵌 7 语言 `game-settings-descriptions.json`（583 键），`/instance/{id}/files/options` 按语言返回；未覆盖语言回退 en-US。
- 游戏内语言映射 `to_minecraft_lang`：zh-HK→zh_tw、ja-JP→ja_jp、ru-RU→ru_ru。
