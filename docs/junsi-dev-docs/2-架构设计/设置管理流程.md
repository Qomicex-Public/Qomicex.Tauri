# 设置管理流程

## 概述

Qomicex Launcher 的设置系统支持应用全局配置的管理。设置以 JSON 格式持久化在 `{DataDir}/QML/settings.json` 中，后端通过 `ISettingsService` 接口提供 CRUD。

## 页面

| 页面 | 路由 | 组件 |
|:---|:---|:---|
| 设置页 | `/settings` | `Settings` (`src/pages/Settings.tsx`) |

## 设置项分类

| 分类 | 设置项 | 说明 |
|:---|:---|:---|
| 数据目录 | dataDir | 游戏数据目录路径（默认 `{QOMICEX_HOME}/QML/`） |
| 游戏目录 | gameDir | Minecraft 根目录 |
| Java | javaPath | 手动指定 Java 路径 |
| 内存 | maxMemory | 最大内存 (MB) |
| JVM 参数 | extraJvmArgs | 自定义 JVM 参数 |
| 窗口 | gameResolution | 游戏窗口分辨率 |
| 下载源 | downloadSource | 下载镜像源（auto / bmclapi / mcim） |
| Mod 源 | modSource | Mod 数据源 |
| 外观 | language | 界面语言 |
| 外观 | fontFamily | 全局 UI 自定义字体家族名（空 = 系统默认） |
| 许可证 | licenseKey | 许可证激活密钥 |

## 设置 API

| 方法 | 路径 | 用途 |
|:---|:---|:---|
| GET | `/api/settings` | 获取所有设置 |
| PUT | `/api/settings` | 更新设置（部分更新） |
| GET | `/api/settings/data-dir` | 获取数据目录路径 |
| PUT | `/api/settings/data-dir` | 设置数据目录 |

## 下载源自动选择

```
GET /api/settings/download-sources/ping    → 各镜像延迟 { bmclapi: 120ms, mcim: 300ms }
GET /api/settings/download-source/auto-select → 返回最优源
```

支持源：`官方（Mojang）`、`BMCLAPI`、`MCIM`，系统启动时自动 Ping 选最快源。

## Mod 源管理

```
GET /api/settings/mod-sources/ping         → 各 Mod 源延迟
GET /api/settings/mod-source/auto-select    → 返回最优源
```

## 系统字体（自定义 UI 字体）

```
GET /api/settings/fonts → 系统已安装字体家族名（去重、排序）
```

- 后端用 `fontdb` crate 枚举系统字体（TTF/OTF/WOFF 等），结果进程内 `OnceLock` 缓存。
- 前端外观设置「字体」卡片：可搜索 Select 选择字体 → `PUT /api/settings` 保存 `fontFamily` → 全局生效（`document.documentElement` 设 `--app-font`，body 优先使用，空则回退系统默认字体栈）；提供「恢复默认字体」重置。

## 背景图片

```
GET  /api/settings/backgrounds           → 列出背景图片
GET  /api/settings/backgrounds/{name}    → 获取背景图片文件
POST /api/settings/open-backgrounds       → 打开背景文件夹
```

背景图片存放在 `{DataDir}/QML/backgrounds/`，用户可自行添加。

## 设置变更事件

前端通过 EventSource 监听 `/api/progress/stream` 间接获取影响设置的变更通知。前端 `src/api/settings.ts` 的 `subscribe` 机制监听 localStorage 变更实现跨组件同步。

## Java 管理

| 操作 | 端点 |
|:---|:---|
| 搜索系统 Java | `GET /api/java/search` |
| 自定义 Java | `GET/POST/DELETE /api/java/custom` |
| 合并列表 | `GET /api/java/list` |
| 验证路径 | `POST /api/java/validate` |
| 版本推荐 | `POST /api/java/recommended` |
| 在线下载 | `POST /api/java/download/start` |

Java 管理整合在设置页中，支持：
- 自动扫描系统已安装的 Java
- 手动添加自定义路径
- 在线下载 Java（支持暂停/恢复）
- 按游戏版本推荐合适的 Java 版本

## 数据目录变更流程

```
PUT /api/settings/data-dir  → 设置新路径
  │
  ▼
后端验证路径有效性
  ├── 有效 → 更新 settings.json
  ├── 不存在 → 尝试创建
  └── 无效 → 返回 400
  │
  ▼
重启生效（提示用户重启启动器）
```
