# 技术选型

## 概述

Qomicex Launcher 是 Minecraft 游戏启动器，采用前后端分离 + 桌面外壳的三层架构。

## 关键决策

- **Minimal API 而非 MVC**: 使用 `MapGet`/`MapPost` 等最小 API 端点，避免传统 Controller 层
- **NativeAOT 发布**: 反射受限，需显式 `JsonSerializerContext` 注册序列化类型
- **文件系统持久化**: 无数据库，所有状态存储在 `{DataDir}/QML/` 下的 JSON 文件中
- **SSE 进度流**: 使用 Server-Sent Events (`/progress/stream`) 统一推送进度更新
- **版本身份隔离**: 实例级 mods/saves/resourcepacks 隔离，通过 `versions/{inst.Name}/` 目录实现
- **Vite 代理**: 开发时 `/api/*` 代理到 `localhost:5000` 后端

## 关键决策

- **Axum 而非框架**: 使用 `Router::nest("/api", ...)` 组装各 endpoint 模块（`endpoints/*.rs`），对应 C# 版 `MapXxxEndpoints` 系列
- **Rust 主后端**: 自 ADR-004 起后端以 Rust (qomicex-backend) 为主，旧 C# 后端 `Qomicex.Launcher.Backend.Neo` 保留在 `legacy` 分支
- **文件系统持久化**: 无数据库，所有状态存储在 `{DataDir}/QML/` 下的 JSON 文件中
- **SSE 进度流**: 使用 Server-Sent Events (`/progress/stream`) 统一推送进度更新
- **版本身份隔离**: 实例级 mods/saves/resourcepacks 隔离，通过 `versions/{inst.Name}/` 目录实现
- **Vite 代理**: 开发时 `/api/*` 代理到 `localhost:5000` 后端
- **CORS**: `CorsLayer::permissive()`，开发环境任意来源
