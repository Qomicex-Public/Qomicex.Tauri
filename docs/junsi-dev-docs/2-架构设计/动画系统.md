# 动画系统

## 概述

启动器使用 GSAP 作为主要动画库，配合 CSS @keyframes 和 Tailwind CSS 动画类，提供流畅的视觉体验。

## 技术栈

| 技术 | 用途 |
|------|------|
| GSAP (`gsap`) | 页面切换、组件进入/退出、列表交错、展开折叠等复杂动画 |
| CSS @keyframes | 基础动画（fadeIn、slideUp 等） |
| Tailwind CSS | 过渡效果（transition-*）、加载动画（animate-spin/pulse） |

## 动画场景

### 1. 页面切换过渡
- **位置**: `Layout.tsx`
- **效果**: 250ms 淡入 + 上滑
- **实现**: `gsap.set` 立即设置 opacity:0 避免闪现，`requestAnimationFrame` 后执行动画
- **触发**: 路由变化时自动执行

### 2. Dialog 进入/退出动画
- **位置**: `packages/plugin-ui/src/components/Dialog.tsx`
- **进入**: 背景淡入 + 内容缩放进入 (scale 0.95→1)
- **退出**: 背景淡出 + 内容缩放退出 (scale 1→0.95)
- **实现**: `isVisible` + `isAnimating` 状态控制，退出动画完成后才卸载 DOM
- **触发**: Dialog 打开/关闭时

### 3. Select 下拉弹出/收起动画
- **位置**: `packages/plugin-ui/src/components/Select.tsx`
- **弹出**: 150ms 缩放 + 上移动画
- **收起**: 100ms 缩放 + 上移动画
- **实现**: `isClosing` 状态控制，关闭动画完成后才卸载 portal
- **触发**: 下拉框打开/关闭时

### 4. 本地实例卡片交错动画
- **位置**: `Instances.tsx` (网格视图)
- **效果**: 子元素依次入场 (stagger 50ms)，从下方淡入+缩放
- **触发**: 列表数据变化时

### 5. 本地实例列表交错动画
- **位置**: `Instances.tsx` (列表视图)
- **效果**: 子元素依次入场 (stagger 40ms)，从左侧淡入
- **触发**: 列表数据变化时

### 6. 远程版本列表交错动画
- **位置**: `Instances.tsx` (下载新版本页面)
- **效果**: 子元素依次入场 (stagger 50ms)，从下方淡入+缩放
- **触发**: 版本列表数据变化或视图模式切换时

### 7. 侧边栏入场动画
- **位置**: `Sidebar.tsx`
- **效果**: 250ms 左滑入场 + 交错效果
- **触发**: 应用启动时

### 8. 目录下拉框弹出动画
- **位置**: `Instances.tsx` (DirPopover)
- **效果**: 150ms 缩放 + 上移动画
- **触发**: 下拉框打开时

### 9. 展开/折叠动画
- **位置**: `useExpandAnimation` Hook + `Settings.tsx`
- **效果**: 平滑高度过渡 (GSAP)
- **触发**: 手风琴、可折叠面板展开/折叠时

### 10. 骨架图→内容切换动画
- **位置**: `ContentTransition.tsx`
- **效果**: 300ms 透明度 + 缩放过渡
- **触发**: 加载状态切换时

## 全局动画控制

### 设置项
- `animationsEnabled`: 全局动画开关
- `animationSpeed`: 速度倍率 (0.5-2)

### 实现机制
- CSS 变量 `--anim-duration-multiplier` 控制 CSS 动画时长
- GSAP 动画通过 `getSettings()` 读取设置并应用倍率
- 属性 `data-anim-enabled="false"` 时禁用 CSS 动画

### 用户设置入口
- 路径: 设置 → 外观 → 动画开关/速度滑块

## 性能优化

### GPU 加速
所有动画使用 `transform` 和 `opacity` 属性：
- `opacity`: 透明度变化
- `y` / `x`: translateY / translateX
- `scale`: 缩放

### 避免 reflow
- GSAP 自动批量处理 DOM 操作
- 使用 `will-change` 提示浏览器优化

### 动画时长
- 页面切换: 250ms
- 组件进入/退出: 150-200ms
- 列表交错: 250-300ms (含 stagger)
- 展开/折叠: 250ms
- 避免超过 500ms 的动画

## 性能优化：列表动画「限动视口 + 滚动暂停」

### 问题
列表/网格插入动画（stagger）在条目多时卡顿到动画显示不出。

### 根因
1. 原实现 `gsap.fromTo(children, ...)` 对容器**全部子节点**创建补间，100+ 条目 = 100+ 并行 tween 主线程逐帧更新；
2. 卡片带 `glass-surface`（`backdrop-filter: blur()`），同时动画几十上百个 blur 元素，合成器每帧重采样 N 次背景——最大元凶；
3. 筛选/搜索每次改动都重播整个列表动画；
4. stagger 随条目数趋 0，所有 tween 同时起跑。

条目规模在几百内，未到 DOM 数量瓶颈（需几千），故**弃用 react-window 虚拟滚动**（高度不一、网格视图不支持、重构风险大），采用限动方案。

### 方案：`useAnimatedList` hook
- **位置**: `src/hooks/useGsapAnimations.ts`
- **只动画前 `MAX_ANIMATE_ITEMS = 35` 个**（覆盖首屏，网格 6 列×5~6 行），其余立即显示为最终态——避免几百个 backdrop-filter 卡片同时进 tween。
- **滚动暂停**: 自动向上查找最近的 `overflow-y` 滚动祖先，滚动时暂停本列表自身的 timeline，停止 200ms 后恢复——滚动时集中渲染，动画不与滚动抢主线程。
- **参数化**: `{ x?, y?, scale?, stagger?, duration?, exitDuration? }`，适配各页面不同方向。
- **调用方**: `Instances.tsx`（本地网格/列表、远程网格/列表）、`Accounts.tsx`（左滑）、`ResourceCenter.tsx`（上滑+缩放）。

### 移除
- `useStaggeredList`（死代码，无调用方）。
- 三页面原始 `useEffect` + `gsap.fromTo(children, ...)` 写法改为 hook。

## useAnimatedList 三缺陷修复

### 缺陷1：骨架图→内容切换无动画
- **原因**：原 `useEffect` 异步执行，骨架图期间 `setItems`/`setScannedLocal` 先触发 deps 变化，此时内容容器未挂载（`ref.current` null）提前 return；内容挂载后 deps 未再变，动画不重播。
- **修复**：改 `useLayoutEffect`（DOM 更新后同步执行）+ 把 `loading`/`scanning`（Instances）、`initialLoading`/`isReplacing`（ResourceCenter）加入 deps。加载状态翻转时内容容器已挂载，动画必播。

### 缺陷2：列表项无退出动画
- **原因**：React 数据变化时旧 DOM 立即卸载，无法直接动画已移除元素；手动 append 到列表容器的克隆会被下一次 reconciliation 清除。
- **修复**：deps 变化后 diff 出被移除的 `data-key` 项，`cloneNode(true)` 后 **append 到 body 层用 `position:fixed`**（视口坐标，不受 React 管理），播淡出+收缩后 `onComplete` 移除。限动前 `MAX_ANIMATE_ITEMS=35` 个，避免大量 blur 卡片同时进 tween。
- **要求**：调用方子元素必须加 `data-key`。
- **位置定位**：旧节点卸载后 `getBoundingClientRect` 归零，须在挂载时记录坐标（`prevRectsRef`），退出克隆才能定位到原位置而非左上角。

### 缺陷3：动画播放中途停顿
- **原因**：滚动暂停用 `gsap.globalTimeline.pause()` **暂停全局时间线**，会影响正在播放的所有动画（含本列表进入动画）；滚动持续时 resume 被推迟。
- **修复**：改存 `tlRef`（`gsap.timeline()` 局部引用），滚动时只 `tlRef.current.pause()`/`resume()`，不影响其他动画。

### 验证（Playwright mock + 真实后端）
- 骨架图→内容：采样到 `item0:0.11→0.71→0.96→1` 交错推进，证明动画播放而非直接跳出。
- 退出动画：切分类后 body 出现 35 个 fixed 克隆，90ms 内淡出移除。
- 停顿：连续采样动画进度连续推进无中断。
