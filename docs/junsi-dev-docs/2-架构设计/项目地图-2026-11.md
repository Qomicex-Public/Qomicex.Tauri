## 0. 30 秒心智模型

**三个进程 + 五个库 + 一个范式。**

```text
Tauri 壳 (src-tauri, 11k 行)  ──解压 sidecar + spawn + 注入管道名──▶  后端 (src-backend, 87k 行)
   单实例 / 深链 / 拖放 / 更新器 / WASM 插件网关                      axum 路由 + service + JSON 落盘
                    │                                                          ▲
                    └──────────── 前端 WebView (src, 59k 行) ──────────────────┘
                                  唯一出口：src/api/*.ts → client.ts / ipc.ts
```

- **没有数据库**。全部状态是 JSON，落在 `{BaseDir}/QML/*.json` 与实例目录下（清单见 §7）。
- **传输双形态**：dev/CI 走 HTTP `127.0.0.1:5000`；release 走 QIPC 命名管道 + `qomicex://` 协议，竖 `QOMICEX_NO_TCP=1` 后端口彻底消失。前端只管调 `src/api`，不感知传输。
- **唯一范式**（背下来即可任意跳转）：
  `页面 → src/api/xxx.ts → client.request → 后端 route → endpoints/xxx.rs → services/xxx.rs → 磁盘 JSON`
- **子模块边界**：协议/引擎在子模块，**业务在后端**。改联机踢人 → 后端 `services/kick.rs`；改穿透算法 → connector 子模块。

## 2. 启动时序（理解一切的前提）

1. `src-tauri/src/lib.rs` 单实例检查 → 解压 `qomicex-backend.exe` 到临时目录 → `spawn_backend()` 注入 `QOMICEX_IPC_PIPE`（+ `QOMICEX_NO_TCP=1`）→ 起窗口。
2. 后端 `main.rs`：切 UTF-8 代码页 → 加载 `.env.local`（debug）→ `AppState::build()` → 装 panic hook → 初始化 tracing + IO 捕获 → **回滚半完成的整合包更新** → 预热 mcmod 索引 → 起 TCP 监听和/或管道监听 → 起父进程看护。
3. 前端 `main.tsx`：装拖动区 + 全局错误上报 → 动态 import `App.tsx`（保证监听器早于依赖求值）。
4. `App.tsx`：`backendState` 三态门控（loading/ready/error）→ 就绪后才注册路由 → 之后再串行触发：设置加载 → 首次向导 → Java 检查 → 插件加载 → 更新检查 → 冷启动深链。

> 读代码顺序建议：`main.rs`(170 行) → `app.rs`(109 行) → `App.tsx`(启动编排) → `lib.rs`(sidecar/spawn)。
