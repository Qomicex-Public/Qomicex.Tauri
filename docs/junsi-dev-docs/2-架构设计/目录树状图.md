## 树状图说明

### 目录层级
- **根目录**: 项目配置、CI/CD、子模块
- **src/**: 前端 React 应用
- **src-backend/**: Rust 后端 API 服务
- **src-tauri/**: Tauri 桌面外壳
- **packages/**: 共享组件库
- **qomicex-***: 外部 Rust 子模块

### 文件颜色编码（按功能）
- **入口文件**: main.rs, App.tsx, lib.rs
- **配置文件**: Cargo.toml, package.json, tauri.conf.json
- **API 层**: endpoints/, api/
- **服务层**: services/
- **组件层**: components/, pages/
- **工具层**: util/, lib/, hooks/
- **资源层**: Resources/, icons/, assets/

### 核心模块关系
```
用户交互 → pages/ → components/ → api/ → endpoints/ → services/
                                              ↓
                                    qomicex-core-rust/
                                    qomicex-downloader-rust/
                                    qomicex-connector-rust/
```

## 树状图说明

### 目录层级
- **根目录**: 项目配置、CI/CD、子模块
- **src/**: 前端 React 应用
- **src-backend/**: Rust 后端 API 服务
- **src-tauri/**: Tauri 桌面外壳
- **packages/**: 共享组件库
- **qomicex-***: 外部 Rust 子模块

### 文件颜色编码（按功能）
- **入口文件**: main.rs, App.tsx, lib.rs
- **配置文件**: Cargo.toml, package.json, tauri.conf.json
- **API 层**: endpoints/, api/
- **服务层**: services/
- **组件层**: components/, pages/
- **工具层**: util/, lib/, hooks/
- **资源层**: Resources/, icons/, assets/

### 核心模块关系
```
用户交互 → pages/ → components/ → api/ → endpoints/ → services/
                                              ↓
                                    qomicex-core-rust/
                                    qomicex-downloader-rust/
                                    qomicex-connector-rust/
```
