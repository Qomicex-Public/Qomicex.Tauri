# ADR-124：整合包安装失败保留已下载文件、重试续传，进度改按文件数计

- 日期：2026-11-03
- 状态：已实施

## 背景

用户安装 All the Mods 10（493 个文件）时，下载到 409 个文件后整批报「下载超时：文件下载未在预期时间内完成」，实例被删除，已下载的 409 个文件一并丢弃，重试只能从零开始。

日志显示两个独立缺陷：

1. **批次看门狗误判**。`download_batch` 只看广播事件是否刷新 `last_event`，而对账分支写在 `tokio::select!` 的 `sleep(5s)` 里——该 future 每轮循环重建，事件持续到达时计时器一直被重置，对账分支被饿死。实测日志为 `done=37 total=50 pending=13 states={"Completed": 13}`：13 个任务已经完成却没计入 `done`，120 秒后整批被取消。事件通道也确实在丢事件（`skipped=3045`）。
2. **进度口径错误**。步骤百分比按 `Σ已下载字节 / Σ已知总字节` 计算，尚未开始的文件对分子分母都是 0，只剩几十个未调度文件时就会冲到 99%；再经 `Math.round` 合成后显示 100%，于是出现「409/493 文件 100%」。

## 决策

1. **活性判定与事件解耦**。主循环固定每 300ms 醒来一次；对账在 `select!` 之外按 1 秒节流，用 `DownloadManager::progress()` 的真实字节数续命，并按 `state()` 补齐终态。`broadcast` 的 `Lagged` 只记录告警，不续命——通道里别的任务在动，不代表本批次在动。
2. **进度按文件数计**：`(已完成文件数 + 在途文件完成度之和) / 总文件数`。已完成的任务不再重复计入在途，未全部完成时不可能到 100%。
3. **失败不再连坐实例**：在线且版本隔离的整合包安装失败时，把版本隔离目录整体移入 `{gameDir}/.qml-install-staging/{key}/payload`，只删除实例记录；重试同一 `source/project/version` 时搬回原位，**只复用大小与暂存记录一致的文件**（暂存时记录相对路径与大小），其余重下。用户主动取消、或用户在下载中心移除任务时删除暂存。
4. **暂存操作的并发与安全约束**：
   - `stash` / `take` / `drop_entry` 用进程内互斥串行化；`stash` 遇到同键条目时保留原条目、不覆盖（并发失败的两个安装各持一份不完整内容）。
   - `take` 在目标版本目录已存在时不做递归删除，直接返回「未命中」：同名实例可能由别的流程创建，删掉会丢用户数据。
   - 暂存键对 `source` 统一转小写，安装入口与删除入口算出同一个键。
   - `DELETE /api/modpack/staging` 校验 `Origin`（只接受本机页面与 Tauri 自定义协议），并核对条目内记录的 `project_id` / `version_id`：后端监听 `127.0.0.1` 且 CORS 放行任意来源，不加这一层，任意网页都能借跨站请求删掉用户的续传文件。
5. **TTL 兜底**：暂存条目保留 7 天，安装入口顺手清理过期条目。

## 后果

- 失败后重试不需要重下已完成的部分。实测断点续传后第二次运行直接补满。
- `.qml-install-staging` 位于 gameDir 下（与 `versions/` 同级、以 `.` 开头），不参与实例扫描；放在启动器数据目录会导致跨卷 `rename` 失败，复制整包代价更高。
- 非版本隔离安装没有独立版本目录可搬，不承诺续传，仍按原逻辑删除。
- 本地导入（无 `project/version` 坐标）同样不承诺续传。
- 合成进度仍会在阶段切换时出现 ≤0.5% 的抖动（步骤权重与并行分支所致），不属于本次范围。

## 验证

- 单测：`batch_percent` 文件数口径、`inflight_credit` 不重复计数、暂存区 `key` 归一化 / `stash-take` 大小记录 / 目标已存在不删除 / 同键不覆盖 / `drop` / TTL（8 例）。
- 真实拉包：Fabulously Optimized 6.5.0（50 个文件）在镜像配置下完成文件批次，`48/50` 时合成进度 80.82%，全程无「未完成却 100%」采样（733 次采样，0 次）。
- 失败注入：拉取 `meta.fabricmc.net` 不可达导致安装失败，确认 18 个已下载文件进入暂存区、实例记录删除；重试日志出现「已从暂存区恢复上次未完成的文件」，文件批次从 18/50 继续到 50/50。
- `DELETE /api/modpack/staging` 返回 `{"dropped":true}` 且暂存目录删除；跨站 `Origin` 返回 403。
