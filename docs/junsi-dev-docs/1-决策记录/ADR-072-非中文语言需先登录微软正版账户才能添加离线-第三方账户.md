# ADR-072：非中文语言需先登录微软正版账户才能添加离线/第三方账户

| 属性 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-09-11 |
| 决策者 | AI Agent |

## 背景

版权合规要求：非中文语言用户需先拥有正版（微软）账户，才能使用离线/第三方登录。当前 Accounts 添加弹窗对 4 种登录方式无任何门禁，任意语言均可直接添加离线/Yggdrasil/统一通行证账户。

## 决策

仅前端 UI 门禁：在 src/pages/Accounts.tsx 用 useI18n().lang + 已加载 accounts 计算 needOfficial = (lang !== 'zh-CN' && !accounts.some(a => a.loginMethod === 'Microsoft'))。为真时禁用离线/Yggdrasil/统一通行证三个 tab（disabled + 变灰 + 点击无效），并在弹窗内显示警示条与「去登录 Microsoft」按钮；useEffect 在门禁生效时强制切回 Microsoft tab。判定「已登录正版」= 存在 loginMethod==='Microsoft' 的账户，不校验 token 有效期。仅限制新增登录，不限制使用已有离线账户启动游戏。i18n 7 语言补 officialRequired/goOfficial 两键。

## 备选方案

### 方案 仅前端 UI 门禁
- 优点：改动最小，仅 1 个文件；与账户列表同源自动重算
- 缺点：直连后端 API 可绕过
- 为何不选：采纳

### 方案 前端 + 后端双重校验
- 优点：不可绕过
- 缺点：后端需感知当前语言（Accept-Language/flag），改动大且语言属前端展示概念
- 为何不选：舍弃

### 方案 抽 useOfficialAccountGate hook
- 优点：可复用
- 缺点：当前仅 1 个调用方，属投机抽象（YAGNI）
- 为何不选：舍弃
