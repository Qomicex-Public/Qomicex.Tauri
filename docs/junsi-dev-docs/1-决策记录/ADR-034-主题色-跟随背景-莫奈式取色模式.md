# ADR-034：主题色「跟随背景」莫奈式取色模式

| 属性 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-08-21 |
| 决策者 | AI Agent |

## 背景

主题色功能（ADR-033）基础上，用户要求新增「跟随背景」模式：用类 Material Monet 算法从当前背景图取主色作强调色，无背景时回退默认主题色。背景由 Layout.tsx 解析为同源 API URL（<img> 显示）。

## 决策

采用实用型 Monet（非完整 HCT/CAM16）：新增 src/lib/monet.ts，把背景图 fetch→blob→canvas 降采样到 ≤48×48 网格，按色相分桶+饱和度加权选主导“有彩色”主色，提饱和/钳明度得强调色。themeColor 用哨兵值 'background' 表示跟随背景（后端 theme_color 为 Option<String> 无需改）。themeColor.ts 改为带渲染序号的状态控制器：applyThemeColor 处理 'background' 走异步取色，Layout 经 setThemeBackground(url) 在背景变化时重取色；无背景/取色失败返回 null→clearVars 回退默认。UI 主题色块加“跟随背景”入口（渐变图标色块）。

## 备选方案

### 方案 完整 Monet（HCT/CAM16 色调板）
- 优点：更正统的动态取色
- 缺点：实现/调参成本高，引入色彩科学库
- 为何不选：未说明

### 方案 仅后端取色
- 优点：后端复用
- 缺点：需新增后端端点 + 图像解码依赖，前端已有同源图直接采样更轻
- 为何不选：未说明
