# ADR-023：i18n 语言集扩展：7 语言 BCP 47 全码 + 全量翻译

| 属性 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-08-17 |
| 决策者 | AI Agent |

## 背景

启动器 i18n 原本只有 zh-CN / zh-TW（占位复用 zh-CN）/ en-US / en-GB 四种语言，其中 zh-TW 无真实文本。用户要求补齐 zh-TW 并新增繁体中文（香港）、日语、俄语，全部语言统一采用 BCP 47 全码格式。游戏设置描述 JSON（583 键/语言）由后端 options.rs 经 include_str! 直接消费，需同步扩展。

## 决策

语言集定为 7 个 BCP 47 全码：zh-CN / zh-TW（台湾繁体）/ zh-HK（香港繁体）/ en-US / en-GB / ja-JP / ru-RU。全部 19 个资源文件（18 TS 模块 + game-settings-descriptions.json）全量翻译，TS 结构经 satisfies TranslationSchema 编译期校验与 zh-CN 一致；JSON 键名不变（583 键）。启动器 LANGS/SUPPORTED/detectSystemLang 与后端 options.rs（include_str! 表 + to_minecraft_lang：zh-HK→zh_tw、ja-JP→ja_jp、ru-RU→ru_ru）同步扩展。游戏内语言回退：未覆盖语言经 get_description 回退 en-US。

## 备选方案

### 方案 zh-TW 保持占位，只新增 ja/ru
- 优点：工作量小
- 缺点：繁体用户仍看到简体文本
- 为何不选：用户明确要求 zh-TW 真实翻译

### 方案 日语用 ja 或 jp 代码
- 优点：ja 为 ISO 标准码
- 缺点：与现有 en-US/en-GB/zh-TW 的区域限定命名模式不一致
- 为何不选：用户选定 ja-JP 全码，浏览器 navigator.language 可天然匹配

### 方案 新语言 JSON 复用 en-US 回退
- 优点：省去 JSON 翻译
- 缺点：游戏设置说明仍为英文
- 为何不选：用户要求全量翻译
