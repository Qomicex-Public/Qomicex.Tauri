# ADR-071：个性化增强：视频/动图背景、默认材质细化参数、主题跟随系统

## 背景

启动器外观个性化此前仅支持静态图片背景（backgroundImage → <img>，bgBlur/bgOverlayOpacity）与 5 种组件材质（default/frosted/acrylic/aero/liquid，仅 glassBlur 一个可调参数），主题模式仅 dark/light。用户要求：1) 背景支持视频/动图并提供开关；2) 不同材质有各自的细化参数（毛玻璃类可调模糊、默认材质可调卡片透明度/边框颜色/厚度）；3) 主题模式支持跟随系统。后端 get_background 此前硬编码返回 image/png，无法正确服务视频/动图。

## 决策

1) 背景：后端 SettingsResponse 新增 background_animations_enabled（None/true=开，默认开）与 background_video_enabled（None/false=关，默认关）；get_background 按扩展名返回 MIME（png/jpg/gif/webp/apng/avif/bmp/svg/mp4/webm/ogv/mov）。前端 Layout 按扩展名判定 bgType：视频用 <video autoplay muted loop playsinline>，动图用 <img>，动图关闭时用 canvas 截首帧（GIF/APNG/WebP 无原生停帧）；视频关闭时不渲染背景。2) 材质细化：SettingsResponse 新增 card_opacity（0-100，默认 100）、card_border_color（hex）、card_border_width（px，默认 1），仅 default 材质生效；index.css 用 :root[data-material="default"] .glass-surface 读取 --card-opacity/--card-border-color/--card-border-width，App.tsx 与 Settings.tsx 的 saveSettings 依据设置写入这三个变量（默认值移除变量回退主题）。glassBlur 保持对非 default 材质生效。3) 主题：theme 支持 'system'，App.tsx 用 matchMedia('(prefers-color-scheme: dark)') 解析并在 change 事件时实时重解析（仅 system 模式响应），启动引导脚本也处理 'system'。i18n 新增 8 键（themeSystem + 卡片 3 项×2 + borderNone/Thick + 背景动图/视频×2），同步 7 语言。

## 备选方案

### 方案 动图关闭时改用静态首帧服务端渲染
- 优点：前端无需 canvas
- 缺点：需引入图片解码库（gif/apng 首帧提取），后端依赖膨胀
- 为何不选：前端 canvas drawImage 即可取首帧，零依赖

### 方案 所有材质共用一套透明度/边框参数
- 优点：实现更简单
- 缺点：玻璃材质的透明度/边框由材质本身定义，强行覆盖会破坏观感
- 为何不选：按用户需求只给 default 材质暴露这些参数

### 方案 theme=system 仅启动时判定一次
- 优点：实现更简单
- 缺点：系统主题切换后需重启才生效，体验差
- 为何不选：matchMedia change 监听成本低，实时响应体验更好

### 2026-09-11 更新
## 追加修订：默认材质卡片透明度默认值 100 → 50（v1.1）

### 变更
默认材质卡片透明度（`cardOpacity`）的默认值由 100（完全不透明）改为 50（半透明），使默认材质的分类卡片呈现半透明玻璃观感。

同步位置：
- `src/api/settings.ts` `DEFAULT_SETTINGS.cardOpacity: 50`（字段注释同步）
- `src/App.tsx` `applyCardStyle`：回退默认 50，且始终写入 `--card-opacity`（不再在 100 时移除变量）
- `src/pages/Settings.tsx` `saveSettings` 与 slider `value`/显示回退默认 50
- `src/index.css` `:root[data-material="default"] .glass-surface` 的 `--card-opacity` 回退值 `1` → `0.5`
- `src-backend/qomicex-backend/src/settings.rs` `card_opacity` 字段注释（`None` = 前端默认 50）
