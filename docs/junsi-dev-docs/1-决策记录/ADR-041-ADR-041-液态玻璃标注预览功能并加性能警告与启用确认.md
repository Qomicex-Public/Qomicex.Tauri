# ADR-041：ADR-041：液态玻璃标注预览功能并加性能警告与启用确认

## 背景

液态玻璃材质（quidlass LiquidGlass）对每个 Card 实例运行 backdrop-filter + SVG feDisplacementMap 位移折射并跟踪鼠标弹性形变，单卡片成本可控，但长列表场景（模组管理几十上百个 ModCard）同时存在大量实例时 GPU/CPU 开销叠加，实测明显卡顿甚至界面无响应卡死。用户要求短期先不做渲染层优化，而是明确告知风险：将液态玻璃标注为「预览功能」并给出性能提示。

## 决策

三层提示：① 下拉选项文案改为「液态玻璃（预览）」（新 i18n 键 componentMaterialLiquidPreview，7 语言）；② 选中 liquid 时在材质选择器下方常显琥珀色警告条（沿用 Accounts 页现成 amber 样式，faTriangleExclamation 图标，componentMaterialLiquidWarning 键）；③ 从非 liquid 切换到 liquid 时经 useMessageBox msgConfirm 弹确认框（componentMaterialLiquidConfirmTitle/Body 键），取消则不写入设置、Select 受控值自动回退。i18n 改动位于 qomicex-tauri-i18n 子模块（types 由 zh-CN DeepStringify 推导，其余 6 语言同步补键）并单独提交（786567a）。
