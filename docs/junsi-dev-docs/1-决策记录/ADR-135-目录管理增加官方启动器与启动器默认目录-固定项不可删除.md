# ADR-135：目录管理增加官方启动器与启动器默认目录，固定项不可删除

| 属性 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-18 |
| 决策者 | AI Agent |
| 关联 | issue #360、ADR-025（目录管理「当前目录」占位）、ADR-122（游戏目录搬迁） |

## 背景

issue #360：目录管理默认是空的，而实际默认游戏目录是一个看不出位置的 `.minecraft`。用户要求目录管理固定存在两个不可删除的默认目录：

- 官方启动器目录（Mojang 的 `.minecraft`）；
- 启动器安装/默认游戏目录。

实测与代码事实：

- 目录管理（`src/pages/Instances.tsx`）只列 `localStorage['qomicex-directories']`，列表为空就是空态；`currentDir` 取 `settings.gameDir`，后端默认是 `$HOME/.minecraft`。
- 官方启动器的目录与 `$HOME/.minecraft` 不是同一个位置：Windows 是 `%APPDATA%\.minecraft`，macOS 是 `~/Library/Application Support/minecraft`，Linux 仍是 `~/.minecraft`。
- 前端能拿到启动器数据目录（`/settings/data-dir`），但官方目录没有任何出口。

## 决策

1. 目录管理固定展示两个默认目录：
   - **官方启动器目录**：由后端按平台解析，经 `/systeminfo` 的 `officialGameDir` 暴露；
   - **启动器默认目录**：`{数据目录}/.minecraft`（前端用 `settings.dataDir` 拼接）。
2. 固定项**并入 `qomicex-directories` 数组**并带 `fixed: 'official' | 'launcher'` 标记，因此可以与用户目录混排、顺序随现有 `saveDirs` 持久化。加载时按当前设置校正固定项路径；与固定路径重复的普通目录会被剔除。
3. 固定项**不可删除、不可重命名**（右键菜单与行内按钮都不提供），可设为当前、可打开、可上移/下移；名称取 i18n（`instances.officialDir` / `instances.launcherDefaultDir`）。
4. 新装/设置重置的默认 `gameDir` 改为 `{数据目录}/.minecraft`（`SettingsResponse::default` 走 `default_game_dir()`）。已有用户保存过 `gameDir`，不受影响；已有实例各自的 `gameDir` 也不变。
5. 固定目录首次出现时插在列表最前面（官方在前、启动器默认第二）；此后顺序由用户控制。

## 备选方案

### 固定项固定在顶部，不参与排序
- 优点：实现最简单，不需要合并进持久化数组
- 缺点：用户要求「允许排序」，固定项置顶无法满足
- 为何不选：不采纳

### 固定项放独立数组，只持久化顺序
- 优点：与用户目录数据分离
- 缺点：渲染、拖拽、去重都要维护两套列表；顺序还要额外存一份
- 为何不选：不采纳：状态面更大，收益只有数据洁癖

### 只展示固定目录、不修改默认 gameDir
- 优点：不改变新装落点
- 缺点：默认 `.minecraft` 仍然指向 `$HOME`，issue 的「不知道在哪」没有真正解决
- 为何不选：不采纳：用户明确选择把默认目录放到数据目录下

### 官方目录用前端 Tauri path API 计算
- 优点：不碰后端
- 缺点：`appDataDir` 在 Linux 是 XDG 目录、macOS 需要拼 `minecraft`（无点），跨平台规则分散
- 为何不选：不采纳：后端解析一次、所有客户端共用

## 影响

- `src-backend/qomicex-backend/src/settings.rs`（`default_game_dir()` + 单测，默认 `gameDir` 变更）
- `src-backend/qomicex-backend/src/models.rs`（`SystemInfoResponse.official_game_dir`）
- `src-backend/qomicex-backend/src/endpoints/system.rs`（平台解析 + 响应字段）
- `src/types/index.ts`（`SystemInfo.officialGameDir`）
- `src/pages/Instances.tsx`（`ManagedDir.fixed`、合并固定项、禁用删除/改名、下拉与弹窗统一渲染）
- `qomicex-tauri-i18n/src/{zh-CN,zh-TW,zh-HK,en-US,en-GB,ja-JP,ru-RU}/instances.ts`（`officialDir` / `launcherDefaultDir`，子模块单独提交）
- `docs/junsi-dev-docs/3-API规范/API列表.md`（`/system/info` 新字段）

## 风险

- 新装默认游戏目录从 `$HOME/.minecraft` 变为 `{数据目录}/.minecraft`；老用户已保存的 `gameDir` 与实例路径不变。回滚只需还原默认值，不涉及数据迁移。
- 官方目录首次可能不存在：扫描为空，打开时才由后端 `create_dir_all` 创建。
- 用户清空 localStorage 后，固定项会重新插入到列表最前，自定义顺序丢失（与现有目录列表同样的语义）。
- 数据目录修改后需要重启启动器才生效（现有设置行为），固定项路径在下次挂载时校正。
