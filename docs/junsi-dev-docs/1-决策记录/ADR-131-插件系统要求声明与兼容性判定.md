# ADR-131：插件系统要求声明与兼容性判定

| 属性 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-17 |
| 决策者 | AI Agent |

## 背景

插件可能依赖特定 OS/架构/系统版本。原先 manifest 无法声明，商店安装按钮也无法在下载前提示不兼容。商店 API 为独立仓库，需要启动器与商店共同约定字段与判定口径。

## 决策

manifest 新增 systemRequirements.os[]（name/version/arch/allow）。判定集中在启动器 Rust 后端 services/plugin_compat.rs：无声明全支持；只有 true 为白名单；只有 false 为黑名单；两者都有时按声明，命中的 false 优先，未命中按支持。商店代理为列表/详情补 systemSupported，安装按钮禁用；本地导入与商店安装在共享安装管线统一拒绝 PLUGIN_UNSUPPORTED_SYSTEM。商店从 plugin_versions.manifest_json 透出字段，不加列。

## 备选方案

### 方案 前端 TS 判定
- 优点：少一次后端改动
- 缺点：OS/架构/版本归一逻辑重复，Rust/TS 易漂移
- 为何不选：不采用

### 方案 安装时下载包再判断
- 优点：无需商店改字段
- 缺点：白下载包，按钮无法提前禁用
- 为何不选：不采用

## 影响
- services/plugin_compat.rs 新增判定与单元测试
- PluginManifest.systemRequirements、PluginInfo.systemSupported
- install_from_dir / install_from_package 拒绝不兼容系统
- 商店代理列表/详情补 systemSupported
- 商店列表/详情版本透出 systemRequirements
- PluginStoreBrowse 按钮禁用 + 文案；PluginCard 已装标注
