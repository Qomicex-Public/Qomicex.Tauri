# ADR-134：同包重装复用既有实例，重启后待补全不降级失败

| 属性 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-18 |
| 决策者 | AI Agent |
| 关联 | ADR-118（待补全阻塞清单）、ADR-124（失败安装保留文件）、ADR-133（补全入口） |

## 背景

两个用户可见的问题，同一组根因：

1. 整合包安装停在「待补全」时关闭并重启启动器，任务变成失败（`实例目录已被占用: Better MC [FORGE] BMC4`），点重试仍然失败，最终只能删卡。
2. 从分享页深链唤起的安装失败后，卡片没有重试按钮。

代码层事实：

- 失败安装会**保留**实例记录与半装产物（ADR-118 的 `blocked-mods.json`、ADR-124 的暂存区），这是刻意设计。
- 但 `POST /modpack/install` 每次都走 `InstanceService::create`，同名同目录直接返回「实例目录已被占用」。于是重试、以及深链在重启后被重放，都只能撞死在这一步，永远无法恢复。
- `InstallTracker` 只存在内存：启动器重启后 `GET /modpack/progress/{id}` 返回 not-started。下载中心的陈旧任务处理只对**已经标记为** `awaiting-files` 的卡片查磁盘清单；被持久化成 `downloading`/`queued` 的卡片直接判 `taskExpired` 失败，用户再也回不到补全入口。
- 深链安装走 `installModpackDirect`，前端只弹 Toast、不建卡片；卡片由 SSE 按 instanceId 自动补建，而补建的卡片没有 `retry` 描述符，失败后没有重试按钮。

## 决策

1. `install()` 在建实例前按「同 `name` + 同游戏根目录」查找现有记录；满足以下任一身份条件时**复用**该记录而不是新建：
   - 记录带来源字段：`modpack_source` / `modpack_project_id` / `modpack_version_id` 与本次请求一致；
   - 记录不带来源字段（`install-direct` 刻意不写，issue #118）：`modpack_name` 与本次包名一致。
   用户自建的同名实例（无 `modpack_name`）不会被接管，仍按原行为报占用。
2. 复用目标仍有非终态任务时直接返回该 instanceId，不重复起管线（避免重放把正在下载的任务顶掉）。
3. 复用重装时按 `size + sha1` 过滤已完整落盘的下载目标（`target_file_complete`，与暂存区恢复同一套校验），避免把几百个已下好的模组再下一遍。
3. 下载中心的 not-started 分支先查实例的待补全清单（`GET /modpack/blocked/{id}`）：有条目 → 转回 `awaiting-files`；清单为空/查询失败才走原来的过期判定。`server` / `plugin` 任务跳过（它们不是实例语义）。
4. 深链安装成功后由 `DeepLinkHandler` 按请求坐标建下载卡（含 `retry` 描述符）；SSE 到达时按 `instanceId` 更新同一张卡。Technic 无 `fileId`、无法通过 `/modpack/resolve` 重试，不建带重试的卡。

## 备选方案

### 方案 重试前删除实例再重建
- 优点：不用改安装入口
- 缺点：删记录仍留版本目录，重建会「接管」半装内容；若连目录一起删，用户已下载的文件与 op/设置全丢
- 为何不选：不采纳：把恢复动作变成破坏性操作

### 方案 后端持久化 tracker，重启后自动续传
- 优点：真正恢复中断安装
- 缺点：管线状态、下载句柄、进度都需要落盘与重建；涉及面远大于本次问题
- 为何不选：不采纳为本次修复；当前复用记录后用户点一次重试即可续上（已下载文件由暂存与校验跳过）

### 方案 深链安装不建卡，只在失败时弹窗提供「重试」
- 优点：不动下载中心
- 缺点：重试仍要复刻一次安装请求，且重启后弹窗已消失
- 为何不选：不采纳：卡片 + 持久化描述符才能跨重启保留入口

- `docs/junsi-dev-docs/3-API规范/API列表.md`（`/modpack/install` 复用语义）

## 风险

- 同名同包同目录的重装现在会覆盖既有实例的模组与清单内容（原先直接报错）。这是「重装」语义，且用户必须显式发起；不同版本、不同来源不会复用。
- 复用记录的版本隔离方式沿用请求值（重试与重放都沿用原请求），若用户中途手动改过隔离方式，重装会按请求值执行。
