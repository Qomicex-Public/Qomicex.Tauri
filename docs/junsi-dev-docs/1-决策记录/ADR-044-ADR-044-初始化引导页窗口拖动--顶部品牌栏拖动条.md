# ADR-044：ADR-044：初始化引导页窗口拖动——顶部品牌栏拖动条

| 属性 | 内容 |

| 日期 | 2026-08-23 |
| 决策者 | AI Agent |

## 背景

初始化引导页 InitialSetupWizard 是 fixed inset-0 z-[9998] 全屏覆盖层（盖住 TitleBar），根 div 虽带 data-tauri-drag-region 但 Tauri v2 只在 mousedown 直接命中的元素自身带该属性时才调用 start_dragging；wizard 的品牌栏/进度条/内容区(flex-1 实心)/底栏四层子容器铺满整窗，mousedown 永远命中无属性的子元素 → 窗口完全无法拖动。权限层正常（capability 已含 core:window:allow-start-dragging），纯前端结构问题。

## 决策

方案 A：顶部品牌栏改造为拖动条。品牌栏 div 加 data-tauri-drag-region + select-none；内部 logo img 与文字容器加 pointer-events-none 使 mousedown 穿透到带属性的容器本身（Tauri 判定条件满足）。Playwright mock 实测：logo/文字/空白三个位置 elementFromPoint 均返回带 drag-region 属性的元素，中央步骤卡片对照组不带属性（点击不误触发拖动），语言 Select 与「下一步」按钮交互不受影响。

## 备选方案

### 方案 仅品牌栏拖动（已选）
- 优点：克制、类标题栏心智、改动最小
- 缺点：可拖面积小，用户需精确瞄准顶部条
- 为何不选：用户明确选择 A

### 方案 全页空白可拖
- 优点：到处能抓体验好
- 缺点：四层容器全部加属性，视觉上无边界暗示哪里能拖
- 为何不选：被用户否决
