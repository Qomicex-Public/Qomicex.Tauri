# ADR-075：亮色模式液态玻璃底色改为中性灰低透明度

| 属性 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-09-11 |
| 决策者 | AI Agent |

## 背景

亮色模式下液态玻璃呈纯白，看不出模糊与折射。根因：亮色 --card 为 0 0% 98%（近白），liquid 卡片底色用 hsl(var(--card)/0.42)，近白 42% 叠在 quidlass 的 backdrop-filter 层上，把模糊/位移淹没成纯白。Layout 的 bg-background/50（亮色为纯白）进一步叠加加重。实测：light rootBg rgba(250,250,250,0.42) vs dark rgba(21,23,30,0.42)。经与 tag v0.1.0-alpha20260822.0 逐字符比对，liquid CSS 10 条规则、Card.tsx、useMaterial.ts 完全一致 → 非代码回归，是亮色配色固有缺陷。

## 决策

在 src/index.css 新增亮色专属覆盖 `.light[data-material="liquid"]`：`.glass-surface` 与 `[data-liquid-glass]` 底色改为 hsl(228 10% 88% / 0.18)（中性灰、低不透明度），并单独调亮色边框色/内高光/投影。仅覆盖亮色 liquid，暗色与其他材质不变。

## 备选方案

### 方案 降全局 bg-background/50 白遮罩
- 优点：壁纸更透
- 缺点：影响所有材质与无壁纸场景，改动面大
- 为何不选：舍弃

### 方案 亮色下统一改全部玻璃材质底色
- 优点：一致性更好
- 缺点：超出本次问题范围，需逐材质重新调色
- 为何不选：舍弃

### 方案 仅覆盖亮色 liquid 底色为中性灰低透明度
- 优点：最小改动，只影响 liquid，不碰暗色与其他材质
- 缺点：无
- 为何不选：采纳
