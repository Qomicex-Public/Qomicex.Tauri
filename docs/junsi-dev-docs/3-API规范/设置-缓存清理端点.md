# 设置 — 缓存清理端点

设置页「存储」分区的缓存清理能力。所有端点均为 `POST /api/settings/<name>`，无需请求体，统一响应 `{ "deleted": <删除文件数> }`（`camelCase`）。内存型缓存（CurseForge）由 service 自行返回清理条目数。

| 端点 | 清理对象 | 落盘位置 |
|------|---------|---------|
| `/settings/clear-cache` | Forge 版本列表 HTML 缓存 | `%TEMP%/ForgeVersionCache/*.html`（core `provider_forge::get_cache_file_path`） |
| `/settings/clear-curseforge-cache` | CurseForge 版本列表内存缓存 | 进程内存（`curseforge_fetch.clear_cache()`） |
| `/settings/clear-neoforge-cache` | NeoForge 版本缓存 | `%TEMP%/NeoForgeVersionCache/*.json` |
| `/settings/clear-ftb-cache` | FTB 整合包市场列表缓存 | `{BaseDir}/QML/cache/ftb/*.json`（core `FtbBase` 落盘） |
| `/settings/clear-mods-list-cache` | 所有实例模组列表缓存（6h TTL） | `{BaseDir}/QML/mods-cache/*.json` |
| `/settings/clear-mod-updates-cache` | 所有实例模组更新检查缓存（6h TTL） | `{BaseDir}/QML/mods-update-cache/*.json` |
| `/settings/clear-modpack-temp` | 整合包导入上传/解压临时文件 | `{BaseDir}/temp/modpack-uploads/` + `{BaseDir}/temp/multimc-imports/`（递归删文件，保留目录） |

实现位于 `src-backend/qomicex-backend/src/endpoints/system.rs`：`delete_files_in_dir`（按扩展名递归删）、`delete_all_files_in_dir`（递归删全部文件）、`walk_dir_files`（迭代式目录遍历，避免深目录递归爆栈）。前端 API 在 `src/api/settings.ts`，UI 在 `src/pages/Settings.tsx` 存储分区（每类一行 + MorphActionIcon 清理按钮）。

注意：清空模组列表缓存时前端同步 `cacheInvalidate('api-instance-')` 清内存缓存（`src/lib/simple-cache.ts`），避免命中 30s 内存缓存导致显示未刷新。

## GET /api/settings/cache-stats — 缓存统计

返回 6 类磁盘缓存的文件数与总大小（字节），与各 clear-* 端点清理范围一一对应；CurseForge 内存缓存不纳入（无文件大小语义）。

```json
{
  "forgeVersions": { "files": 0, "bytes": 0 },
  "neoforge": { "files": 0, "bytes": 0 },
  "ftb": { "files": 1, "bytes": 2050 },
  "modsList": { "files": 1, "bytes": 1026 },
  "modUpdates": { "files": 0, "bytes": 0 },
  "modpackTemp": { "files": 0, "bytes": 0 }
}
```

实现位于 `src-backend/qomicex-backend/src/endpoints/system.rs`：`delete_files_in_dir` / `delete_all_files_in_dir`（清理）、`stat_files_in_dir` / `stat_all_files_in_dir`（统计）、`walk_dir_files`（迭代式目录遍历，避免深目录递归爆栈）。含单测 `stat_and_delete_count_files_recursively`。前端 API 在 `src/api/settings.ts`（`getCacheStats`），UI 在 `src/pages/Settings.tsx` 存储分区：进入 launcher 标签页时拉取统计，`cacheStatText` 渲染「N 个文件 · 大小」（`formatCacheSize` 自动 B/KB/MB/GB），各缓存行 description 内嵌显示（`whitespace-pre-line` 换行），清理成功后 `refreshCacheStats()` 刷新。

注意：清空模组列表缓存时前端同步 `cacheInvalidate('api-instance-')` 清内存缓存（`src/lib/simple-cache.ts`），避免命中 30s 内存缓存导致显示未刷新。
