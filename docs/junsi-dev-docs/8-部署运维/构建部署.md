# 构建与部署

## 开发环境

### 前置要求

| 组件 | 版本要求 | 用途 |
|:---|:---|:---|
| Node.js | >= 18 | 前端构建 |
| .NET SDK | 10.0 | 后端构建 (NativeAOT) |
| Rust | latest stable | Tauri 桌面外壳 |
| PowerShell | 5.1+ (Windows) / pwsh (其他) | 构建脚本 |

### 前端开发

```bash
# 纯前端开发 (端口 1420)
npm run dev

# 构建 (tsc → vite build，类型错误会失败)
npm run build
```

### 后端开发

```bash
cd src-backend/Qomicex.Launcher.Backend.Neo
dotnet run    # 端口 5000
```

Vite 开发服务器将 `/api/*` 代理到 `localhost:5000`。

### Tauri 桌面开发

```bash
npm run tauri dev    # 启动 Tauri 窗口 + 前端 + 后端
```

## 构建系统

### GitHub Actions CI/CD

配置文件: `.github/workflows/release.yml`

### 触发方式

1. **workflow_dispatch** — 手动触发，填写版本参数
2. **release:published** — GitHub Release 发布时从 tag 解析版本

### 版本格式

```
v<major>.<minor>.<patch>-<type><序数>.<补丁/构建>
```

| 类型 | 序数来源 |
|:---|:---|
| release | 手动输入 |
| beta | 手动输入 |
| alpha | 自动取当天日期 + 当日构建序号 |

### 构建参数

| 参数 | 说明 | 可选值 |
|:---|:---|:---|
| `buildPlatform` | 目标平台 | `windows`, `linux`, `macos`, `loongarch64`, `all` |
| `linuxBundles` | Linux 打包格式 | `appimage`, `deb`, `rpm` 组合 |
| `macosArch` | macOS 架构 | `both`, `arm64`, `x64` |
| `windowsArch` | Windows 架构 | `both`, `arm64`, `x64` |
| `licenseRequired` | 启用许可证验证 | boolean |
| `prerelease` | 标记为 Pre-release | boolean |

### 构建流程

```
1. 解析版本参数 → 构造标准版本号
2. 按 RID 发布后端 (dotnet publish -p:LicenseRequired=<bool>)
3. 后端二进制嵌入 src-tauri/binaries/
4. Tauri 构建 → 生成平台安装包
```

### 本地 Release 构建

```bash
# Windows
pwsh ./build-release.ps1
```

## 项目结构

```
qomicex-launcher/
├── src/                          # React 前端
├── src-tauri/                    # Tauri Rust 桌面壳
├── src-backend/
│   ├── Qomicex.Launcher.Backend.Neo/  # 主 API (ASP.NET Core 10 NativeAOT)
│   ├── Qomicex.Core.AOT/              # 核心引擎 (子模块)
│   ├── Qomicex.Downloader.Refactor/   # 下载器
│   └── Qomicex.Connector.Part.Scaffolding/  # 连接器 (子模块)
├── scripts/                      # 构建/测试脚本
├── .github/workflows/            # CI/CD
└── docs/                         # 文档
```

### Git 子模块

```bash
git submodule update --init --recursive
```

## 跨平台构建

| 架构 | Windows | macOS | Linux |
|:---|:---|:---|:---|
| x64 | MSI/NSIS | DMG | AppImage/Deb/Rpm |
| ARM64 | MSI/NSIS | DMG | 支持 |
| LoongArch64 | - | - | 支持 |
| RISC-V 64 | - | - | 支持 |

## 持续集成

- 需要 `QOMICEX_PAT` 密钥用于子模块 checkout
- 后端按 RID 发布后嵌入 Tauri 二进制目录
- 构建产物为各平台原生安装包
