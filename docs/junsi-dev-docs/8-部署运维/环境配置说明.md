# 环境配置说明

## 开发环境要求

### 必须安装

| 软件 | 版本 | 验证命令 |
|:---|:---|:---|
| Node.js | >= 18 | `node --version` |
| npm | >= 9 | `npm --version` |
| .NET SDK | 10.0 | `dotnet --version` |
| Rust | latest stable | `rustc --version` |
| Tauri CLI | ^2 | `npm run tauri -- --version` |

### 可选工具

| 工具 | 用途 |
|:---|:---|
| PowerShell 7+ | 构建脚本 (`build-release.ps1`) |
| Git LFS | 大文件支持 |
| Visual Studio 2022+ (Windows) | C# 开发 |
| VS Code | 前端开发 |

## 后端配置

### appsettings.json

位于 `src-backend/Qomicex.Launcher.Backend.Neo/appsettings.json`:

```json
{
  "CurseForge": {
    "ApiKey": "<your-key-here>"
  }
}
```

`CurseForge:ApiKey` 已设置在仓库中，一般无需修改。

### NativeAOT 发布

```bash
dotnet publish -c Release \
  -p:LicenseRequired=false \
  -p:IncludeNativeLibrariesForSelfExtract=true
```

`IncludeNativeLibrariesForSelfExtract=true` 对 SkiaSharp 等原生库是必需的。

## 前端配置

### Vite 代理

`vite.config.ts` 中配置 `/api/*` → `http://localhost:5000`，前端开发时无需手动启动后端（Tauri dev 会自动处理）。

### 严格 TypeScript

`tsconfig.json` 启用：
- `strict: true`
- `noUnusedLocals: true`
- `noUnusedParameters: true`

未使用的变量或参数会导致构建失败。

## 子模块初始化

```bash
git clone --recurse-submodules <repo-url>
# 或
git submodule update --init --recursive
```

子模块:
- `src-backend/Qomicex.Core.AOT/`
- `src-backend/Qomicex.Connector.Part.Scaffolding/`

需要 `QOMICEX_PAT` (Personal Access Token) 获取子模块访问权限。

## 环境变量

| 变量 | 用途 | 默认值 |
|:---|:---|:---|
| `QOMICEX_HOME` | 覆盖数据目录路径 | `%LOCALAPPDATA%/Qomicex` |
| `QOMICEX_PAT` | GitHub PAT 用于子模块 | - |
| `ASPNETCORE_ENVIRONMENT` | ASP.NET 环境 | `Development` |

## 端口分配

| 端口 | 用途 | 说明 |
|:---|:---|:---|
| 1420 | Vite 开发服务器 | 前端 |
| 5000 | ASP.NET Core API | 后端 |

## 数据目录

默认路径: `%LOCALAPPDATA%/Qomicex/QML/` (Windows)

结构:
```
QML/
├── settings.json       # 应用设置
├── accounts/           # 账户 (JSON)
├── instances/          # 实例 (JSON)
├── licenses/           # 许可证令牌
├── skins/              # 自定义皮肤
├── backgrounds/        # 自定义背景
└── logs/               # 后端日志
```

可设置 `QOMICEX_HOME` 环境变量覆盖整个数据根目录。

# 环境配置说明

## 开发环境要求

| 软件 | 版本 | 验证命令 |

### 可选工具

| 工具 | 用途 |
|:---|:---|
| PowerShell 7+ | 构建脚本 (`build-release.ps1`) |
| Git LFS | 大文件支持 |
| VS Code | 前端开发 |

## 后端配置

### 后端启动

```bash
# 方式一：npm 脚本（Windows GNU 工具链）
npm run dev:backend

# 方式二：直接 cargo（默认 stable 工具链）
cd src-backend/qomicex-backend && cargo run
```

### 端口与环境变量

| 变量 | 用途 | 默认值 |
|:---|:---|:---|
| `QOMICEX_PORT` | 后端监听端口 | `5000` |
| `QOMICEX_HOME` | 覆盖数据目录路径 | `%LOCALAPPDATA%/Qomicex` |
| `QOMICEX_PAT` | GitHub PAT 用于子模块 | - |

后端默认绑定 `127.0.0.1:5000`。

### 许可证验证 (可选 feature)

```bash
# 启用许可证验证（对应 C# 版 -p:LicenseRequired=true）
cargo run --features license-required
```
