# 关于页鸣谢列表

## 概述

设置页「关于」中的鸣谢区块（`SettingSection` 标题 `settings.about.acknowledgements`）展示三类来源：

- **服务与数据源**：Modrinth / CurseForge / FTB / BMCLAPI / mcmod / Minecraft 官网等，可点击跳转外链。
- **个人贡献者**：xphost008、Strawxg、OakChaser、飘飘白云等，与「开发者」区块区分——**开发者区块（`CONTRIBUTORS`）仅限项目发起人 / 主要开发者**，提 issue、测试、适配等贡献者归入鸣谢。
- **泛化条目**：如「所有为启动器提供反馈的人」，无头像时用 `Users` 图标占位。

## 数据来源

`src/constants/credits.ts` 的 `SERVICES: CreditService[]`。

```ts
interface CreditService {
  name: string
  description: string
  url?: string   // 可选：个人贡献者可能不希望公开链接
  icon?: string  // public/ 下相对路径；缺省渲染 Users 图标
}
```

- `url` 缺省时条目不可点击、不显示外链图标（用于不愿公开个人主页的贡献者）。
- `name` 与 `description` 默认中文，渲染时经 `SERVICE_NAME_KEYS` / `SERVICE_DESC_KEYS`（`src/pages/Settings.tsx`）查 i18n key 翻译；未映射则直接显示原文。

## i18n

文案位于 i18n submodule `qomicex-tauri-i18n/src/<lang>/settings.ts` 的 `about` 命名空间，7 种语言（zh-CN / zh-TW / zh-HK / en-US / en-GB / ja-JP / ru-RU）必须同步：

| key | 用途 |
|:---|:---|
| `serviceStrawxgDesc` | Strawxg 说明 |
| `serviceOakChaserDesc` | OakChaser 说明 |
| `servicePiaoPiaoBaiYunDesc` | 飘飘白云说明 |
| `serviceAllContributorsName` / `serviceAllContributorsDesc` | 泛化「所有反馈者」条目 |

## 头像资源

`public/avatars/`：`Strawxg.png`、`OakChaser.png`、`PiaoPiaoBaiYun.png`（与开发者头像同目录）。
